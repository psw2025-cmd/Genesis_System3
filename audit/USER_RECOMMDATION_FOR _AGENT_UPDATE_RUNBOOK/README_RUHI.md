# #RUHI User Recommendation Reference Pack

Marker: `SYSTEM3_RUHI_USER_REFERENCE_V1`  
Owner intent: every Genesis System3 agent should inspect this pack when planning
frontend, backend, data, model, orchestration, cloud, proof or UI/UX work.

## Mandatory practical-thinking rule

`#RUHI` means reconstruct the real problem from current authority, identify the
first failing boundary, implement the smallest durable solution, and prove the
result where the user sees it. Agents must ask for each relevant artifact:

1. What trader/operator problem is this visual or note trying to solve?
2. Which current API, store, component, model, job or cloud service owns it?
3. Is the displayed value real Dhan truth, transparent derivation, PAPER
   simulation, historical evidence, degraded state, placeholder or design-only?
4. What current-main test and exact-serving production-browser/API proof would
   demonstrate success?
5. What safety, licensing, rate-limit, privacy, cost or leakage boundary applies?
6. What remains unfinished, who owns it, and what is the highest-gain next action?

Agents must use `#RUHI` in Issue #188 progress/ownership records for work derived
from this pack. A repeated label alone is not compliance; the reasoning and proof
must be visible in the task, test and production acceptance.

## Evidence classification

- PNG files are user-provided design references. They communicate layout,
  information-density and workflow intent; they do not prove implemented APIs,
  current prices, model accuracy, broker connectivity or production readiness.
- `AGENT_CORDINATION_CLOUD.txt` is an advisory coordination input. Revalidate
  every current-state statement against current GitHub/GCP/UI evidence.
- `FOR_INFO_FOR_IMPROMENT.txt` is incomplete and ends at
  `https://token.actions.githubus`. Its issue numbers, percentages and narratives
  are `UNVERIFIED` until freshly checked.
- Dhan remains the exclusive broker/live Indian market authority. External sites,
  screenshots and AI output never masquerade as Dhan truth.
